The engine lives in `src/engine/`. `StoryState` retains source-backed inventory bounds, explicit AVG values, unknown ending state, and three-valued condition/branch evaluation separately from playback `StageState`. The repository loads `maps/story-source.json`; delivered ActivityActions produce distinct mutation records. Restart restores a story checkpoint; default loads reset it and explicit developer loads can preserve it. `FlowDispatcher` executes ordered configure/talk/movie/unsupported actions. `ScriptRunner` owns commands and navigation; `StageEngine` and `StageScheduler` emit start/option/end operations once per visit. The pure `StageState` reducer stores their logical targets; `StageTransitions` samples a separate presentation against the injected monotonic clock. `src/ui/ManualReader.ts` observes this runner and owns text reveal/input state separately; text callbacks send no runner commands. `src/ui/DialogueBacklog.ts` observes dialogue/selection events and captures immutable formatted entries. React reads runner, reading and backlog snapshots through `useSyncExternalStore`; renders and effects schedule or replay no stage operations. The page entry point owns backlog/reader/runner disposal, including HMR, independently of StrictMode subscription cleanup. These engine modules import neither React nor DOM APIs.

`StoryPlaythrough` queues authored activity actions and scene loads, retaining continuation/checkpoint state. `StoryProgress` constructs each quest’s descendants from its listed heads, preserves pending unlocks, and checks live availability at delivery. `StoryMechanics`, `StoryItems`, and `StoryGames` apply native behavior/exam, inventory/shop/gift, scratch, and raffle rules. Ending traversal follows graph order, using frozen attributes/favor/influence/exams and live inventory/AVG state. Rewards execute at their source trigger; History, rerendering, and checkpoint restoration do not execute them again.

```ts
const runner = new ScriptRunner(); // Timed by default; inject clock for tests.
const unsubscribe = runner.onEvent(event => console.log(event));
if (runner.load(script, manifest, { storySource })) runner.start();
runner.getSnapshot().stageState;
runner.advance();              // Dialogue, or a determined hidden branch.
runner.choose(optionIndex);    // displayed index, not AVG optionId
runner.overrideHiddenChoice(optionIndex); // Explicit debug branch only.
runner.setInstantTransitions(true);       // Drain in order; snap visuals.
runner.restart();              // Roll back to script-entry story state.
runner.resetStory();           // Forget all facts, then replay.
unsubscribe();
runner.dispose();             // Cancel scheduled and presentation callbacks.
```
